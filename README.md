## 📌 Projetos em Destaque

### 📊 License Dashboard (Python & Data Engineering)
Pipeline de processamento de dados para auditoria interna, análise de inatividade e otimização de custos de licenças.
- Desenvolvido em **Python** utilizando **Pandas** para engenharia e manipulação de grandes volumes de dados.
- **Pipeline de ETL:** Executa ingestão, tratamento de exceções, higienização de strings e normalização relacional de múltiplas fontes (Excel/CSV).
- **Arquitetura Leve:** Gera dashboards interativos offline em HTML/JS puros e automação de empacotamento ZIP para stakeholders.

### 📊 True One - Roblox Exporter (Python Automation Add-on)
Ferramenta para automação de pipelines de assets gráficos, focada em validação em tempo real e isolamento de processos.
- Desenvolvido em **Python** utilizando a API nativa `bpy` do Blender.
- **Engenharia de Software:** Implementa gerenciamento estrito de contexto (`try/finally`) e tratamento de erros *fail-safe* para mitigar vazamentos de memória (Memory Leaks).
- **Manipulação Avançada de Dados:** Executa clonagem profunda de estruturas complexas em memória RAM temporária, preservando dados originais do ambiente de produção.

### 🤖 Cosmo (Companion AI Engine)
Ecossistema de inteligência assistida local focado em arquitetura desacoplada baseada em dados (Data-Driven).
- Desenvolvido em **GDScript** para Godot Engine 4.6.
- **Pipeline de NLP Local:** Implementa uma Cadeia de Responsabilidade determinística para análise léxica e roteamento atômico de intenções em runtime.
- **Maturidade de Código:** Static Typing Mandatório (tipagem estática estrita), controle de concorrência assíncrona (`await`) e gerenciamento de cache via algoritmo LRU.

### 🧹 Windows Disk Management Automation (Scripting & Otimização)
Solução modular voltada para remediação automatizada de armazenamento e integração de canais de comunicação.
- Desenvolvido em **PowerShell (.ps1)** e **Batch (.bat)**.
- **Integração via API:** Coleta dados do sistema operacional, estrutura payloads em formato JSON e consome Webhooks para alertas em tempo real (ChatOps).
- **Lógica e Controle:** Implementa regras de filtragem baseadas em consultas WMI/CIM e chaves de registro do S.O. para expurgo seguro e condicional de dados.
